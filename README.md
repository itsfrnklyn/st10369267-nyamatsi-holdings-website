# Nyamatsi Holdings Website

Official website for Nyamatsi Holdings.

## About the Project

This website provides information about Nyamatsi Holdings, its company background, services, products and contact details.

## Technologies Used

- HTML
- CSS
- JavaScript
- Firebase Authentication
- Cloud Firestore

## Features

- Company information and services
- User registration and login
- Google Sign-In
- User profile management
- Service booking submissions
- Booking history
- Administrative dashboard
- Booking status management
- Responsive website design
